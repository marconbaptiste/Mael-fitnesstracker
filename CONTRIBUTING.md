# 🤝 Guide de contribution

Merci de vouloir contribuer à ce projet !

## Comment contribuer

1. **Fork** le projet
2. **Crée une branche** pour ta fonctionnalité : `git checkout -b feature/ma-fonctionnalite`
3. **Commit** tes changements : `git commit -m 'Ajout de ma fonctionnalité'`
4. **Push** sur ta branche : `git push origin feature/ma-fonctionnalite`
5. Ouvre une **Pull Request**

## Idées de contributions

- [ ] Persistance des données (localStorage)
- [ ] Mode sombre / clair
- [ ] Export PDF du programme
- [ ] Minuteur intégré pour les exercices
- [ ] Notifications de rappel
- [ ] Graphique de progression du poids
- [ ] Version mobile native (React Native)
- [ ] Support multilingue

## Standards de code

- Composants React fonctionnels avec hooks
- Styles CSS-in-JS ou module CSS
- Commentaires en français
- Commits en français

## Signaler un bug

Ouvre une issue avec :
- Description du problème
- Étapes pour le reproduire
- Comportement attendu vs observé
- Screenshot si possible
